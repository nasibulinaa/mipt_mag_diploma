# Поиск похожих статей по математике

В данном репозитории представлены артефакты работы над работой "Анализ сходства научных математических статей по формулам и их контексту".

Структура:

* [data](./data/) - данные, использованные в работе;
* [papers](./papers/) - копии части научных статей, использованных в процессе данной работыp;
* [presentations_and_docs](./presentations_and_docs/) - документы данной работы (отчеты, презентации, тексты статей);
* [notebooks](./notebooks/) - notebook-и данной работы с кодом;
* [outdated](./outdated/) - неактуальные notebook-и.
