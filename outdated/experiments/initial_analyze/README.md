## RAG

Данные для тестирования расположены в соответствующем репозитории (папка `data/for_rag`). В этих данных есть две статьи (один целевой, другой на ту же тему), в которых содержится релевантная информация по вопросам, которые будут заданы LLM-модели, и 5 других статей, не относящихся к теме. Все статьи отобраны таким образом, чтобы их парсинг мог быть произведён прямым извлечением текстовых данных, то есть без OCR. Статьи взяты из общедоступного датасета [link](https://huggingface.co/datasets/PleIAs/Math-PDF/).
Критерием оценки является количество баллов (максимум 10). Корректно отвеченных вопрос и правильное указание на документ дают 1 балл. Если был найден релевантный документ, без целевого, или были добавлены лишние документы, то зачисляется 0.5 балла. Если ответ на вопрос был корректен, но документ не указан, добавляется уточнение по требованию ссылки на документ. Если после этого документ был найден, зачисляется 0.5 балла.

Первым был протестирован LightRAG. Индексация проходила около 30 минут. После тестирования система получила 1.5 баллов. Поиск выполняется быстро, в пределах 5 секунд. Такой плохой результат обоснован, тем что было построено некорректный граф знаний, в котором символы формул считаются отдельными фактами. Возможно, это из-за самой простой модели `qwen3:0.6b`, но с более тяжёлыми моделями система неспособна обработать тексты без ошибок на оборудовании, использованным в данной работе.
 
Вторым был протестирован RAGLite. Индексация проходила около 1.5 минуты. После тестирования система получила 3 балла. Поиск проходит достаточно долго (около 30 секунд) для каждого запроса. Примечательно, то система выдала ложный результат при анализе последней формулы, так как она её опознала как другу формулу с ошибкой. 
Шаги тестирования с промежуточными результатами можно найти в соответствующих notebook-ах.
Таким образом, существующие готовые решения на основе RAG демонстрируют удовлетворимые результаты поиска по тексту, но при этом неспособны корректно производить поиск по математическим формулами (они не связывают с ними смысл).

## OCR

В данной таблице не учитываются технологии, использованные в протестированных RAG-системах, так как они используют прямой экспорт текста из PDF, что не будет работать со страницами-изображениями или текстами со специфичной кодировкой в PDF-файлах.
