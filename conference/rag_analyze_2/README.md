# Анализ RAG систем

Вторая итерация анализа RAG-систем. 

Начальная информация взята из двух источников:
* https://arxiv.org/pdf/2509.16780 - тестирование RAG+GraphRAG на корректность ответа на вопросы с математическим содержанием. Работа содержит метод оценки корректности поиска.

Использованы, как и раннее, две системы:
- [LightRAG](https://arxiv.org/pdf/2410.05779) - GraphRAG
- RAGLite

LightRAG заменён на GraphRAG для упрощения оценки (нету неиспользуемого веб-сервера)
RAGLite заменён на llama_index для упрощения оценки + это более популярный фреймворк.

Метрики (https://habr.com/ru/companies/econtenta/articles/303458/):
* p@K
* NDCG
* MRR

Вместо использования python библиотеки python `ranx` были использованы реализации алгоритмов из [этой](https://www.geeksforgeeks.org/nlp/evaluation-metrics-for-retrieval-augmented-generation-rag-systems/) мини-статьи про оценку RAG.

Так как используются метрики оценивания ранжирования, будет дополнительно использован rerank для улучшения результатов.

Что можно улучшить при оценке:
* Использовать дополнительную модель для проверки результата (проверка текста): https://arxiv.org/pdf/2505.02811v2 (тут используют для переобработки запроса).
* Увеличение датасета и авто-генерация запросов с ground-truth для оценки.
