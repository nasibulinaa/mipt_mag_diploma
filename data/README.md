# Данные

Данные, используемые в данной работе.

В папке `eng` находится описание датасета английских научных статей, файлы с работами на схожие темы и ссылка на архив с основной частью датасета.
В папке `rus` находится техническое описание датасета файлов научных статей на русском языке.

> Примечание датасет `eng_work` восстанавливается на основе данных из `eng`.
