# Про данные датасета

> ВАЖНО: Датасет приватный. Его распространение не предполагается.

Это датасет научных работ на русском языке по математике и физике, содержащих __математические формулы__.

Техническая иформация о датасете:

Датасет включает только PDF-файлы, без разметки. Названия файлов представляют собой их номера, то есть не содержат полезной информации.

Документы датасета содержат как вложенные в текст формулы (inline-формулы), так и выделенные формулы (outline-формулы).

PDF-файлы имеют следующие представления:
* текстовое (возможен прямой экспорт текста)
* текстовое с некорректной кодировкой (прямой экспорт возможен частично)
* сканы, то есть - графическое (прямой экспорт невозможен, требуется OCR).

Состав статей:
* 1136 статей - "Известия высших учебных заведений" с 1997 по 2007 годы;
* 3892 статьи - трудов журнала "Вестник ТГУ".

Общее количество файлов (PDF): 5000.
